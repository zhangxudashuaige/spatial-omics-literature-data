# 数据字典

## 知识图谱三元组

| 字段 | 说明 |
|------|------|
| head | 头实体（药物/基因/疾病等） |
| relation | 关系类型（cause/process/effect等） |
| tail | 尾实体 |

**注意**: 三元组列顺序需实际核验，不根据文件名猜测。

## 实体类型

| 类型 | 说明 |
|------|------|
| drug | 药物/化合物 |
| gene | 基因/蛋白 |
| disease | 疾病 |
| cell_line | 细胞系 |
| perturbation | 扰动条件 |

## 关系类型

| 关系 | 说明 |
|------|------|
| cause | 因果关系 |
| process | 生物过程 |
| effect | 效应关系 |
| 其他 | 需实际核验 |

## 数据划分

| 划分 | 说明 |
|------|------|
| train | 训练集三元组 |
| test | 测试集三元组 |
| valid | 验证集（如有） |

**注意**: 检查训练测试划分方式，记录是否为官方划分。

## 版本区分

- **2024预印本版本**: 论文对应的数据版本
- **当前仓库版本**: GitHub仓库最新版本
- **上游数据库最新版**: LINCS等数据库的最新版本
- 上游数据库最新版不能冒充论文原始版本

## 示意数据标注

若使用自制示例数据，必须明确标注"示意数据"，不能冒充真实数据。
