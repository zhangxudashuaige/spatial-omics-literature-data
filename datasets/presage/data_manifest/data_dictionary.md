# 数据字典

## 实验表达数据 (h5ad)

| 字段 | 说明 |
|------|------|
| X | 表达矩阵（需确认是原始计数还是归一化对数表达） |
| layers | 其他表达层（如 counts） |
| obs.perturbation | 扰动基因 |
| obs.condition | 实验条件（perturbed/control） |
| obs.cell_type | 细胞类型/细胞系 |
| obs.batch | 批次信息 |
| obs.non_targeting | 是否为非靶向对照 |
| var.gene_name | 基因名称 |
| var.hvg | 是否为高变基因 |

## 处理后的平均响应

| 字段 | 说明 |
|------|------|
| perturbation | 扰动基因 |
| cell_type | 细胞类型 |
| delta_expression | 扰动后平均表达减去对照均值 |
| n_cells | 该扰动的细胞数 |

**预处理逻辑**: 从归一化对数表达减去对照均值，再按扰动求平均。HVG之外可能补回被扰动基因，因此输出不一定只有5,000列。

## 基因嵌入

| 字段 | 说明 |
|------|------|
| gene_key | 基因标识（Gene Symbol/Entrez/Ensembl） |
| embedding_dim | 嵌入维度 |
| source_name | 嵌入来源名称（GenePT等） |
| coverage | 覆盖基因比例 |
| missing_handling | 缺失基因处理方式 |

## 基因角色区分

| 角色 | 说明 |
|------|------|
| 输入基因 | 模型输入的基因（可能包含嵌入覆盖的基因） |
| 输出响应基因 | 模型预测表达响应的基因（通常为HVG+被扰动基因） |
| 外部先验基因 | 同一基因在其他允许使用的数据集中出现，记为外部先验 |

## 数据划分

| 划分 | 说明 |
|------|------|
| train | 训练集扰动 |
| valid | 验证集扰动 |
| test | 测试集扰动 |

**注意**: 目标系统测试扰动的真实响应不加入训练。同一基因在其他允许使用的数据集中出现，应明确记为外部先验。

## 表达值类型

- **原始计数**: 整数，非负
- **归一化对数表达**: log1p(CP10K)，可能为小数
- **平均响应**: 扰动平均 - 对照平均，可能为负值

不把归一化表达误存成原始计数。
