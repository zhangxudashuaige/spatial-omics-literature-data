# TABULA 数据目录

- `raw/`：完整 Census 导出或其他大型数据，仅本地保存，Git 忽略。
- `sample/`：查询脚本输出目录，以及固定 commit 的 `vocab.json` 代码资源。

`vocab.json` 是“基因名称到整数 token ID”的映射，不是细胞 × 基因表达矩阵，也不能证明论文 15M 预训练细胞已经重建。当前固定 commit 中它有 60,697 项；论文正文报告的训练词表为 23,156 基因，两者必须分开解释。

查询生成的 `sample.h5ad` 默认仍被忽略，因为 CELLxGENE 中每个源数据集可能有各自许可证。只有逐项核实来源许可后，才应决定是否公开小样例。
