# CellCap 论文

论文：**CellCap**（单细胞扰动预测模型）。

- 官方代码：<https://github.com/broadinstitute/CellCap>
- 本仓库数据模块：[`datasets/cellcap/`](../../datasets/cellcap/)

CellCap 是一个用于预测单细胞扰动响应的计算模型。本条目保存 CellCap 论文使用的模拟数据、人单核细胞数据、Norman CRISPRa 数据（GSE133344）和 EGA 受控数据，以及下载脚本、预处理脚本、检查工具和配置文件。

大型表达矩阵（.h5ad）和模型权重（.pt）不进入普通 Git 历史。EGA 受控数据仅记录 accession 和申请流程，不尝试下载。

> 论文 DOI 和第一作者待确认，以官方仓库 README 为准。
