# Vespucci 论文

论文：**Identification of Perturbation-Responsive Regions and Genes in Comparative Spatial Transcriptomics Atlases**。

- 论文：<https://doi.org/10.1101/2024.06.13.598641>
- 方法代码：<https://github.com/neurorestore/Vespucci>
- 论文复现代码：<https://github.com/neurorestore/vespucci-analysis>
- 本仓库数据模块：[`datasets/vespucci/`](../../datasets/vespucci/)

Vespucci 是一个用于比较空间转录组图谱中识别扰动响应区域和基因的计算方法。本条目保存 Vespucci 使用的多套空间转录组数据集，包括作者新产生的小鼠脊髓损伤/衰老/治疗数据（GSE268779）、Vespucci 模拟数据、脑损伤（GSE226208）、心肌梗死（GSE214611）、ALS（GSE120374）、脊髓损伤康复（GSE184369/370）和阿尔茨海默病 STARmap PLUS（SCP1375）。

所有数据来源必须从作者代码仓库、GEO、SRA、Zenodo、Broad Single Cell Portal或原始论文核实，不得根据名称猜测。大型 FASTQ 和完整表达矩阵不进入普通 Git 历史。
