# 资源分类规则

## 1. pretraining_corpus

用于自监督或多任务预训练的大规模细胞集合。它可能来自多个平台，可能只公开来源清单和预处理脚本，而不公开一份可直接下载的完整包。

不能把以下内容当成训练语料本身：

- 模型权重（`.pt`、`.ckpt`、`.safetensors`）
- 模型源代码
- 下游微调数据
- CELLxGENE、GEO 等数据平台首页

## 2. downstream_benchmark

用来评价或微调模型的数据。一个数据集可承担多个任务，因此在 `downstream_datasets.csv` 中只保留一个 `dataset_id`，再通过 `task_model_matrix.csv` 建立多对多关系。

## 3. data_platform

用于检索、浏览、下载许多研究的系统。平台本身不是一个实验数据集。`Human Cell Atlas` 在不同语境中既可指联盟/平台，也可指研究集合；本项目在平台表中记录其生态，在数据表中记录其作为模型参考图谱的使用。

## 4. model_repository

模型代码、权重和安装文档。只有原论文、作者/机构主页或论文明确链接的仓库才标记 `official`。未找到官方代码时保留空值和 `unverified`，不会拿第三方复现充数。

## 原始论文判定

优先级：

1. 产生该数据的原始实验论文。
2. 首次正式发布该图谱或基准的论文。
3. 若是聚合平台，记录平台论文，并在备注中要求继续追溯子研究。
4. 若是厂商演示数据且没有独立论文，明确写“无独立数据论文”。
5. 若综述只写技术类别而没有唯一 accession，写“综述未唯一指定”，不猜。
