# Lin et al.（2024）SCTrans

论文：**SCTrans: Multi-scale scRNA-seq Sub-vector Completion Transformer for Gene-selective Cell Type Annotation**，IJCAI 2024。

- 正式论文：https://www.ijcai.org/proceedings/2024/0658.pdf
- 本仓库数据模块：[`datasets/sctrans/`](../../datasets/sctrans/)

SCTrans 没有产生新数据集，而是使用 Zheng68K、Baron、Xin、Segerstolpe、Muraro、MacParland 和 Lung 七个公开人类 scRNA-seq 数据集。模块登记明确 accession、原始数据论文和下载脚本；论文未给出的精确预处理和随机种子不会被伪装成完全复现。
