# SpaGCN 评测数据的原始论文

SpaGCN 自身没有产生这些公开空间组学数据。为防止只记住 SpaGCN 而找不到真正数据来源，本页集中记录原始论文：

| 数据 | 原始论文 | DOI/入口 |
|---|---|---|
| 人胰腺癌 ST | Moncada et al., 2020 | <https://doi.org/10.1038/s41587-019-0392-8> |
| 人 DLPFC Visium | Maynard et al., 2021 | <https://doi.org/10.1038/s41593-020-00787-0> |
| 小鼠脑 Slide-seqV2 | Stickels et al., 2021 | <https://doi.org/10.1038/s41587-020-0739-1> |
| 小鼠视觉皮层 STARmap | Wang et al., 2018 | <https://doi.org/10.1126/science.aat5691> |
| 小鼠嗅球 Spatial Transcriptomics | Ståhl et al., 2016 | <https://doi.org/10.1126/science.aaf2403> |
| 小鼠下丘脑 MERFISH | Moffitt et al., 2018 | <https://doi.org/10.1126/science.aau5324> |

具体下载入口和状态见 [`spagcn-data/data_manifest.csv`](../../spagcn-data/data_manifest.csv)。10x 小鼠脑是供应商公开数据页，不冒充成独立论文。
