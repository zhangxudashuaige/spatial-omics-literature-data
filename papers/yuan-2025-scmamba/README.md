# Yuan et al.（2025）scMamba

论文：**scMamba: A Scalable Foundation Model for Single-Cell Multi-Omics Integration Beyond Highly Variable Feature Selection**。

- 论文：<https://arxiv.org/abs/2506.20697>
- 官方代码：<https://github.com/23AIBox/scMamba>
- 固定代码 commit：`4887c0a8ab060b2482384d2294fe265b633d2406`
- 本仓库数据模块：[`scmamba-data/`](../../scmamba-data/)

scMamba 使用成对 RNA+ATAC 或 RNA+ADT 数据进行多组学整合，并评测大规模图谱、细胞注释、轨迹和迁移能力。本条目保存八套论文数据的来源、规模、状态和检查工具；没有精确处理文件的条目保持 unresolved，不以同名版本冒充。
