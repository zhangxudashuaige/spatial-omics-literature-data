# 数据说明

## 1. 生物样本与空间单位

研究对象是一枚男性 CS8 人胚胎。作者将胚胎横切为 10 µm 组织切片，并在间隔取片的设计下对 62 张切片进行 Stereo-seq。论文最终保留 38,562 个 bin50 空间点，重建胚胎的三维形态和转录状态。

`bin50` 表示把芯片上相邻的 50×50 个 DNB 聚合为一个空间网格。它与“经过细胞分割得到的单细胞”不是同一个概念。论文把它视为近似细胞尺度，但其信号仍可能来自一个以上的细胞。

## 2. 数据关系

```text
HRA005567：128 对 FASTQ（256 文件）
          │
          ├─ R1/f1：Stereo-seq 空间条形码与 UMI
          └─ R2：cDNA 序列
                    │
                    ▼ SAW 5.4.0 + GRCh38/Ensembl 93 + 芯片 mask/图像
             每张切片的表达矩阵与二维坐标
                    │
                    ▼ PASTE 1.3.0 相邻切片配准
             统一的 x、y、z 坐标
                    │
                    ▼ SCC：表达邻接图 + 空间邻接图
             空间 cluster 与胚胎组织
                    │
                    ├─ marker / 外部单细胞参考：细胞类型注释
                    ├─ 轨迹、regulon、细胞通信与跨物种比较
                    └─ cs8.3dembryo.com 在线三维展示
```

公开原始目录中的 128 个 run 是测序/技术拆分单位，并不等于 62 张组织切片。官方元数据可识别 12 个实验分组 `CP1-1` 至 `CP1-12`，但没有给出完整的“run—芯片—组织切片—最终 slice_id”映射。

## 3. 数据源

- `HRA005567`：原始测序和 run 统计文件。
- `PRJCA019863`：BioProject 总入口。
- Zenodo `10851179` / GitHub 标签 `STO-analysis`：作者分析代码快照。
- Cell 补充表：marker、cluster 名称、细胞数、转录因子模块、同源基因。
- `cs8.3dembryo.com`：交互式结果展示。
- 外部 E-MTAB/GSE 图谱：细胞类型注释、时期比较和跨物种比较，不是本研究新产生的原始数据。
