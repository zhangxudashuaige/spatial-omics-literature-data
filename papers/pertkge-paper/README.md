# PertKGE 论文

论文：**PertKGE**（基于知识图谱嵌入的扰动预测方法）。

- 论文：https://doi.org/10.1101/2024.04.08.588632 (2024预印本)
- 官方仓库：https://github.com/myzhengSIMM/PertKGE
- 本仓库数据模块：[`datasets/pertkge/`](../../datasets/pertkge/)

**归类**: 药物靶点预测／扰动转录组知识图谱

PertKGE 使用知识图谱嵌入方法进行药物靶点预测和扰动转录组分析。

本条目保存六类资源：
1. 作者处理后的图谱数据（cause.txt/process.txt/effect.txt/test.txt）
2. 实体与关系映射及数据划分
3. 模型权重
4. LINCS 上游表达数据（Phase I GSE92742、Phase II GSE70138）
5. 生物知识数据库来源
6. 案例与对接资源

只进行数据归档与说明，暂时不训练模型。
