# Peidli et al.（2023）scPerturb

论文：**scPerturb: a unified resource for perturbation analysis**。

- 论文：<https://www.nature.com/articles/s41592-023-02144-y>
- 网站：<https://www.sanderlab.org/scPerturb/>
- 官方代码：<https://github.com/sanderlab/scPerturb>
- 本仓库数据模块：[`datasets/scperturb/`](../../datasets/scperturb/)

scPerturb 是一个统一的单细胞扰动数据库，整合了遗传扰动、药物扰动、多模态等多种类型的扰动实验数据，提供标准化的 AnnData 格式和 E-distance 统计方法。

本条目保存 scPerturb 数据库的 Zenodo 数据入口（RNA+蛋白质 13350497、ATAC 7058382）、文件清单、下载脚本、MD5 校验工具、数据检查程序和最小示例。完整 43GB 数据不进入普通 Git 历史。
