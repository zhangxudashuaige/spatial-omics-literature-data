# 数据集概览

## 官方记录

- GEO：`GSE278603`，2025-06-19 公开，2026-01-18 更新处理后文件。
- 生物样本：E7.5、E7.75、E8.0 完整 WT 小鼠胚胎，每阶段两个重复。
- 测序：Stereo-seq，DNBSEQ-T7，双端布局；GEO 样本页说明使用 SAW 和 STAR v2.5.3、参考基因组 GRCm38。
- 处理后文件：六个 H5AD，打包为 `GSE278603_RAW.tar`，GEO 报告压缩包大小约 802.8 MB。
- 原始数据：BioProject `PRJNA1168072` / SRA study `SRP536234`。

## 口径差异

Cell 正式论文摘要报告 285 张连续切片；GEO 摘要写 360 张、10-µm 厚切片。这里把它视为来源元数据差异，分析时优先以正式论文方法和真实 H5AD 内容为依据。

## 数据层级

1. SRA：原始测序 reads，体量远大于处理后文件，不自动下载。
2. GEO H5AD：处理后表达、注释和空间坐标的容器；字段必须实际检查。
3. scRNA-seq：外部参考，用于细胞类型标注，不是本文新产生数据。
4. SEU-3D：三维浏览系统，不是另一套原始测序数据。
5. coFAST：空间感知的聚类算法。
